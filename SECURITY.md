# Security and safety reports

## Supported versions

Only the latest commit on the default branch is considered for fixes while the
project is in alpha. No release is safety-certified.

## Reporting

For a vulnerability that should not be public immediately, use GitHub's private
vulnerability reporting or Security Advisory feature if enabled on the
repository. Do not publish credentials, Home Assistant tokens, Zigbee network
keys, private IEEE inventories, or unsanitized diagnostics.

For an active water hazard, close the upstream physical shutoff first. GitHub is
not an emergency support channel.

Include the Home Assistant version, device firmware, sanitized Zigbee
signature, exact command parameters, measured physical behavior, and whether a
software OFF command was involved.
